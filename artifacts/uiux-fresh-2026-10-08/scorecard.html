Fix these first

1. Repair resizing and clipped content

After shrinking and expanding the window, the cell outline occupied roughly half the workspace. Checkpoints, Runtimes, and Help lost readable content or reachable actions. Fresh wide startup looked better: test resize transitions as well as initial sizes.

2. Make action availability match runtime state

The palette said to open/start the runtime while an open notebook showed Idle. Actions became available on returning to Notebook. Explain the actual page restriction or support the actions consistently.

3. Finish accessible semantics

Windows UI Automation exposed the palette input but not its command rows; outline entries were absent and the history clear button was unnamed. Keyboard shortcuts and high contrast are good foundations, but screen-reader usability remains unverified.

4. Make checkpoints easier to create and restore

Creation and restoration passed, with a restored session confirmed in the ledger. Add a contextual Create action to the empty page, explicit completion feedback, and conditional trust/version controls.

5. Clarify history and status feedback

Outcome filtering worked. Replace the long syntax-only placeholder with visible filters. Distinguish an operation that completed from code that succeeded, and make reconnection results explicit.
