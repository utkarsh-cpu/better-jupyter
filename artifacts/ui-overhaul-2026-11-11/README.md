# Desktop UI/UX overhaul — 11–12 November 2026

Native window captures of `kernelledger-desktop` on macOS 26.3 (Apple Silicon), resized to 1600 px wide.
They were taken with an isolated profile, a throwaway copy of the macOS sample notebook, and the built-in
`fake` assistant provider, so no real notebook content or network request appears.

- `before-*`: the build before the overhaul. `before-delete-dialog.png` and `before-history-detail.png`
  were taken partway through, after the theme change but before those screens were reworked.
- `after-*`: the branch rebased onto `master` at bf465e2 (including PR #5).

Not shown: VoiceOver, high contrast, and 200% interface scale were not captured here.
